# Chapter: Usage

### Urine test for Albumin - Usage

In a pregnant woman, urine testing for albumin  must be done during each visit.

Testing the urine for presence of albumin  is important for the detection of pre-eclampsia.

Equipments and Supplies:

- Dipsticks
- Urine specimen collection bottles/container
- Watch with seconds
- Gloves

# Chapter: Practical information

### Urine test for Albumin - Practical information

1. Explain to the woman what the test is for and ask for a urine sample.
2. Check the expiry date on the kit and read instructions carefully.
3. Remove one strip and close container tightly.
4. Completely immerse the reagent area of the strip in the urine sample and remove it immediately.
5. While removing the strip run the edge against the rim of container to remove excess urine.
6. Follow manufacture’s recommendations for when it is time to read the results.
7. Compare the yellow-coloured protein reagent part with the albumin results chart on the bottle and record the findings.
8. Explain results to the woman and record on case sheet or MCP card.
